Software Engineer with 7 years of experience building full-stack systems across fintech, cybersecurity, e-commerce, and internal SaaS products. My main stack is TypeScript and Node.js on the back-end, React and Next.js on the front-end. Beyond writing code, I focus on the outcomes it produces — fewer incidents, faster delivery, and systems that hold up under real operational load. I'm currently also working on the AI training side, evaluating and giving structured feedback on AI-generated code and interfaces.
